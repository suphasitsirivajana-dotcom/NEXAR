# settings: ค่าตั้งต้นที่ผู้ใช้ปรับได้

โฟลเดอร์รวม "ค่าตั้งต้น" ของ NEXAR แยกจากโค้ดเพื่อให้หาเจอง่าย (โครงสร้างเดียวกับ `Nexbim/settings/`)

| ไฟล์ | คืออะไร |
|---|---|
| `defaults.js` | เลขเวอร์ชันแอป (`APP_VERSION`), สวิตช์ฟีเจอร์ (`LOCATION_FEATURES`), และค่าเริ่มต้นของกล้อง / ระยะก้าว / การแสดงผล |
