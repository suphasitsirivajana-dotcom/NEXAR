แผนที่โฟลเดอร์ (Mind map)

เริ่มที่ NEXAR ด้านซ้าย จัดโครงสร้างเหมือน NEXBIM · แต่ละกิ่งคือโฟลเดอร์ และกิ่งเดียวกันใช้สีเดียวกัน · กดกล่องเพื่อกางกิ่งและอ่านคำอธิบายด้านขวา · กดวงกลม + / − เพื่อกาง/หุบ · ลากพื้นหลังเพื่อเลื่อน · scroll เพื่อซูม (มุมมอง Dev แสดงรายละเอียดทางเทคนิคเพิ่ม)

ชั้นของโค้ด (Layers)

อ่านจากคำสั่ง import ในโค้ดจริง · ชั้นบนเรียกใช้ชั้นล่างได้ ชั้นล่าง (Core) ห้ามเรียก Exporters หรือ App · กดที่ชั้นเพื่อดูความสัมพันธ์

ชั้นที่เลือก ชั้นที่มันเรียกใช้ได้ ชั้นที่เรียกใช้มัน (อาจได้รับผลถ้าแก้) วางแผนไว้
กดที่ชั้นใดก็ได้

กลไกการทำงาน (Mechanisms)

กลไกหลักของ NEXAR ทั้งฝั่ง 3D / AR / พิกัด และการเชื่อมกับ NEXBIM / Revit

ทำแล้วทำบางส่วนยังไม่เริ่ม

ข้อเสนอ: ออกแบบก่อนเขียนโค้ด

ขั้นตอน: ข้อเสนอ → คุณปรับ Architecture / ตอบคำถาม ❓ → อนุมัติ → กำลังทำ → เสร็จ · ไอเดียบางข้อได้แรงบันดาลใจจากโปรแกรมอื่น (เช่น ConstructCraft) แต่ใช้แค่แนวคิด ออกแบบและเขียนเองทั้งหมด ไม่คัดลอกโค้ด
