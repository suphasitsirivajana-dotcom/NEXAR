คู่มือการใช้งาน NEXAR (v2.7.0)

เว็บแอปดูโมเดล BIM (IFC / DXF / GLB) บน iPad, มือถือ และคอมพิวเตอร์ สำหรับเดินตรวจหน้างาน ปักหมุด 3 ประเภทพร้อมพิกัดจริง ถ่ายภาพจัดหมวดอัตโนมัติ เขียนโน้ตด้วย Apple Pencil และส่งออกกลับเข้า Revit / Navisworks / NEXBIM

● Mark (MK) · ทรงกลมเหลือง ■ Note (NT) · ลูกบาศก์น้ำเงิน ▲ Issue (IS) · สามเหลี่ยมแดง ✎ รองรับ Apple Pencil (ไทย/EN) ทำงานออฟไลน์ 100%

1 เริ่มใช้งานใน 5 ขั้น (Quick Start)

  1. เปิดโมเดล: กดปุ่ม Open มุมขวาบน → เลือกไฟล์ .ifc (หรือกด Try sample เพื่อลองกับอาคารตัวอย่าง) โมเดลจะถูกเก็บไว้ในเครื่อง ออฟไลน์ได้ทันที
  2. ตั้งค่าเบื้องต้น (ทำครั้งแรก): กด ⚙ มุมขวาบน → ใส่ชื่อผู้ตรวจ (Author), เลือกหน่วย (m / mm), เลือกรูปแบบเมาส์ (Revit / SketchUp / NEXAR) และติ๊กรายการ UniFormat ที่จะใช้ตรวจหน้างาน
  3. สำรวจโมเดล: สลับโหมดแถบล่างระหว่าง 3D (หมุนดู), Plan (แปลนตัดชั้น), Walk (เดินข้างใน) หรือกด Dist เพื่อวัดระยะ 3 มิติ
  4. ปักจุดหน้างาน: กดปุ่มสีเหลือง Mark แถบล่าง → เลือก ● Mark (IFC), ■ Note หรือ ▲ Issue → แตะลงบนโมเดล พิมพ์หรือเขียนด้วย Apple Pencil และแนบรูปหน้างานได้ทันที
  5. ส่งออกเข้า BIM: กด Export ▾ มุมขวาบน → เลือก IFC Export Spot (เฉพาะจุด 3D ตรง Base Point), IFC Export All (รวมอาคาร), HTML Crop View Report หรือ Excel/JSON แยกชุด
จำไว้: ข้อมูลทั้งหมดเก็บอยู่ในเครื่องของคุณ (ไม่มี Cloud) ถ้าจะย้ายเครื่องหรือสำรองข้อมูล ให้กด Export ▾ → Full Project Backup (.nexar.json) แล้วนำเข้าที่อีกเครื่องครับ

2 รู้จักหน้าจอหลัก (ชี้จุดปุ่มทั้งหมด ①–⑩)

หน้าจอหลักของ NEXAR ใช้เลย์เอาต์ Clean Field UI แถวบน 1 แถว + แถบล่าง 1 แถว เพื่อให้เหลือพื้นที่ดูโมเดล 3D กว้างที่สุดบน iPad และคอมพิวเตอร์ (สลับกลับ Classic Ribbon ได้ใน Settings)

ภาพที่ 1: โครงสร้างหน้าจอหลักของ NEXAR (Clean Field UI) พร้อมวงล้อมและหมายเลขชี้จุดสำคัญ ①–⑩
1
ชื่อโปรเจกต์ (Project ▾)กดเพื่อสร้างโปรเจกต์ใหม่, เปลี่ยนชื่อ, สลับโปรเจกต์ที่เก็บไว้ในเครื่อง หรือลบโปรเจกต์
2
Open (เปิดโมเดล)โหลดไฟล์ .ifc, .dxf, .glb หรือ .obj เข้ามาในโปรเจกต์ (เปิดซ้อนหลายไฟล์ได้)
3
Export ▾ (ส่งออกทั้งหมด)ศูนย์รวมการส่งออก: IFC All / Spot, HTML Crop View, Excel / JSON แยก 3 ชุด, Photo Pack ZIP และ BCF
4
สลับธีม Light / Dark (☀ / ☾)เปลี่ยนเป็นโหมดสีสว่างเมื่อออกแดดหน้างาน หรือสีเข้มเมื่อทำงานในอาคาร
5
Settings (⚙ · คีย์ลัด Ctrl+,)ตั้งค่าทั้งหมด 6 หมวด: ชื่อผู้ตรวจ, หน่วยวัด, รูปแบบเมาส์, คุณภาพ 3D และคลัง UniFormat II
6
แผงขวา (Markups / Views / Info)เปิด/ปิดแผงรายการจุดมาร์ค (กรองตาม ● Mark / ■ Note / ▲ Issue), มุมมองที่บันทึก และข้อมูลชิ้นส่วน BIM
7
3D ViewCube & ปุ่มหมุน [⟲ | ⌂ | ⟳]ลากบนลูกบาศก์เพื่อหมุนรอบอาคาร, แตะหน้า TOP/FRONT/RIGHT เพื่อสแนปมุม, กด ⌂ เพื่อกลับหน้า Home
8
หมุด 3 รูปทรง 3 สีบนโมเดล● เหลือง = Mark (MK), ■ น้ำเงิน = Note (NT), ▲ แดง = Issue (IS) แตะที่หมุดเพื่อซูมดูและแก้ไข
9
Bottom Dock (แถบคำสั่งหลัก)สลับโหมด 3D/Plan/Walk/CAM · วัดระยะ (Dist), ตัดชั้น (Cut), X-Ray, เมนูเพิ่มเติม (•••) · ปุ่ม Mark และ Capture
10
แถบพิกัดและเวอร์ชัน (Status Bar)แสดงพิกัด IFC (X, Y, Z) ของจุดที่จิ้ม/จ่อ Apple Pencil แบบเรียลไทม์ พร้อมหน่วยและเลขเวอร์ชัน

3 การตั้งค่าก่อนเริ่มใช้งาน (⚙ Settings · คีย์ลัด Ctrl+,)

แนะนำให้กดปุ่ม ⚙ มุมขวาบนเพื่อตั้งค่า 6 หมวดนี้ให้ตรงกับสไตล์การทำงานของคุณก่อนออกหน้างาน (ค่าทุกอย่างบันทึกอัตโนมัติและ Export แชร์ให้ทีมได้)

ภาพที่ 2: โครงสร้างหน้าตั้งค่า Settings ทั้ง 6 หมวด
หมวดรายการสำคัญที่ควรปรับ
1. GeneralAuthor name (ชื่อผู้ตรวจที่จะติดไปทุกไฟล์ IFC/Excel) · Interface layout (Clean Field หรือ Classic Ribbon) · Display units (m / mm / cm / ft) และทศนิยมพิกัด (ข้อมูลที่บันทึกยังคงเป็น IFC เมตรเสมอ)
2. AppearanceTheme (Dark / Light / System) · UI accent color · Button size / density (เลือก Touch / iPad เมื่อใช้บนแท็บเล็ต) · เปิด/ปิด ViewCube, Floor Grid, Markup Pins และปรับขนาดหมุด 3D
3. NavigationMouse control preset (NEXAR, Revit, SketchUp) · Touch joysticks (Auto สำหรับ iPad หรือ Always On เพื่อเปิดจอยบนคอม) · Eye height (ความสูงระดับสายตาในโหมด Walk/CAM ค่าเริ่มต้น 1.60 m)
4. Graphics & ARRender quality (ปรับเป็น Lite 1× ถ้าเปิดโมเดลขนาดใหญ่มากหรืออยากประหยัดแบต) · 3D FOV · Camera AR FOV / Opacity
5. Family Presetsคลังมาตรฐาน ASTM E1557 UniFormat II ครบ 85 รายการ (A–G) — คนทำ BIM เข้ามาติ๊กเลือกชุดอุปกรณ์ที่จะตรวจ หรือกด Add & Pin เพื่อเพิ่ม Level 4 (เช่น D5030.10) ส่วนหน้างานจะเห็นแค่ชื่อสั้นๆ อ่านง่าย
6. Shortcuts & Dataรวมคีย์ลัดทั้งหมด + ปุ่ม Export / Import Settings แชร์การตั้งค่าและรายการ UniFormat ให้เพื่อนร่วมทีม + ปุ่ม Reset defaults

4 การดูโมเดล, ตัดชั้น และวัดระยะ 3 มิติ

โหมดมุมมอง (แถบล่างซ้าย)

  • 3D (คีย์ 1): หมุนดูรอบอาคาร (1 นิ้วลาก = หมุน, 2 นิ้ว = ซูม/แพน)
  • Plan (คีย์ 2): แปลนมองตรงจากด้านบนพร้อมเปิดเส้นตัดชั้นให้อัตโนมัติ
  • Walk (คีย์ 3): เดินภายในอาคารด้วยจอยซ้าย (MOVE) / จอยขวา (LOOK) / ปุ่ม ▲▼ ขึ้น-ลง หรือปุ่ม W A S D + Q E บนคอม
  • 3D ViewCube มุมขวาบน: ลากหมุนรอบอาคาร, แตะหน้า TOP / FRONT / RIGHT เพื่อสแนปมุม, กด ⌂ (H) เพื่อกลับมุม Home (คลิกขวาเพื่อตั้งมุม Home ใหม่)

เครื่องมือช่วยตรวจ (แถบล่างกลาง)

  • Dist (คีย์ R): วัดระยะ 3 มิติ — แตะ 2 จุดบนโมเดล จะขึ้นเส้นวัดพร้อมค่า ระยะ 3D, ระยะราบ (XY) และ ต่างระดับ (ΔZ) วัดต่อเนื่องหลายเส้นและกด Undo / Clear ได้
  • Cut: เปิด/ปิด Section Cut แนวนอน — เลื่อนสไลเดอร์ด้านซ้ายหรือกดชื่อชั้น (Level 1, Level 2…) เพื่อตัดดูแปลนทีละชั้น
  • X-Ray: ทำให้โมเดลโปร่งแสงเพื่อมองทะลุเห็นท่อ/โครงสร้างด้านใน
  • ••• (More): รวมคำสั่ง Home, Fit All (F), Save View, เปิด/ปิด Grid/Pins/Lock View, Groups และ Create Site QR

5 การมาร์คหน้างาน 3 ประเภท & ระบบรูปถ่ายอัตโนมัติ

NEXAR v2.7.0 แยกข้อมูลเป็น 3 สายอิสระ ทั้งรหัส, เลขลำดับ, สี และรูปทรง 3 มิติ (เหมือนกันทั้งในหน้าจอ NEXAR, รายงาน HTML และไฟล์ IFC 3D) และเมื่อลบรายการใดออก ระบบจะรันเลขที่เหลือขยับขึ้นให้อัตโนมัติ (Auto-Renumbering) ไม่ทิ้งช่องว่าง

● Mark · MK-001 (M1) ทรงกลมสีเหลือง (Ø180 mm)
สำหรับระบุจุดอุปกรณ์ / UniFormat II (เช่น CCTV, Outlet, Opening) เพื่อ Comply หรือ Automate วาง Family จริงใน Revit
■ Note · NT-001 (N1) ทรงลูกบาศก์สีน้ำเงิน (160 mm)
สำหรับบันทึกข้อสังเกต / โน้ตหน้างาน (รวม Comment+Note เดิมเป็นชุดเดียว) ไว้อ่านอ้างอิงตำแหน่ง ไม่ใช่งานแก้
▲ Issue · IS-001 (I1) ทรงสามเหลี่ยมด้านเท่าสีแดง (240 mm)
สำหรับปัญหาหน้างาน / Clash / Defect / RFI ที่ต้องติดตามผู้รับผิดชอบและปิดสถานะ (Open → Resolved)
ภาพที่ 3: แถบ Mark แบบ 2 ชั้น — กดปุ่ม Mark บน Dock (หรือคีย์ M) เพื่อเปิดใช้งาน
A
เลือกประเภทจุด (Mark / Note / Issue)กดสลับประเภทที่จะปัก — Note และ Issue เมื่อแตะโมเดลจะเปิดกล่องให้พิมพ์/เขียนรายละเอียดทันที
B
โหมด ⚡ 1-Tap (ปักรัวๆ ไม่ต้องกรอกฟอร์ม)เมื่อเปิด ON แตะลงบนผนัง/ฝ้า/พื้นจะวางหมุด Mark (MK) พร้อมจับพิกัด + ผิวที่เกาะ + ทิศหันหน้าทันที
C
ปุ่มกล้อง 📷 (ถ่ายภาพต่อท้ายอัตโนมัติ)เปิดไว้ถ้าอยากให้เด้งกล้องถ่ายรูปทุกครั้งที่แตะปักจุด (หรือค่อยกดปุ่ม Photo ในแผงขวาทีหลังก็ได้)
D
รายการอุปกรณ์สั้นๆ (อ่านง่ายสำหรับหน้างาน)โชว์เฉพาะชื่อสั้นๆ ไม่มีรหัสเลขกวนตา ส่วนรหัส UniFormat (เช่น D5030) แนบอยู่ในข้อมูลเบื้องหลังครบ 100%
E
+ Setup (เลือกชุด UniFormat ที่จะใช้ตรวจ)เปิดคลัง UniFormat II 85 รายการเพื่อติ๊กเลือก/เอาออก หรือเพิ่ม Custom Level 4 ได้ทันที
★
Host Mark (ล็อกวางบนผิวชิ้นงานเดียว)แตะเลือกผนัง/เสา/พื้นในโมเดลก่อน → กดปุ่ม Host Mark บนแถบด้านล่าง เพื่อล็อกวางหมุดเกาะเฉพาะผิวชิ้นนั้นพร้อมเก็บ HostRevitId
ระบบตั้งชื่อไฟล์ภาพอัตโนมัติ (Auto Naming): ไม่ว่าจะถ่าย 0, 1 หรือหลายรูปในจุดเดียวกัน ระบบจะตั้งชื่อและจัดโฟลเดอร์ให้ตรงกันทุกไฟล์ เช่น Marks/D_Services/D5030_Security_Devices/MK-001_D5030_CCTV_Camera_P01.jpg และ Issues/IS-001_Missing_sleeve_P01.jpg พร้อมเชื่อมตรงกับไฟล์ Photo_Directory.csv และ Excel อัตโนมัติ

6 การใช้งาน Apple Pencil & เขียนแปลงเป็นข้อความ (ไทย / อังกฤษ)

NEXAR v2.6+ รองรับ Apple Pencil อัตโนมัติทันทีที่แตะจอ ไม่ต้องเข้าไปเปิดสวิตช์ใน Settings:

  • Auto Palm Rejection (กันอุ้งมือชนจอ): ระหว่างที่หัวปากกาแตะจอ ระบบจะกันสัญญาณจากอุ้งมือไม่ให้เผลอซูม/หมุนโมเดล หรือเผลอแตะพื้นหลังปิดกล่อง Note
  • Apple Pencil Hover (iPad Pro / Air รุ่นใหม่): จ่อหัวปากกาเหนือโมเดลจะเห็นวงเป้าเล็งสีเหลือง + โชว์พิกัด (X, Y, Z) ล่วงหน้าก่อนแตะจริง
  • แถบสลับ ⌨ Type | ✎ Pencil ข้างช่องข้อความ: แตะเพื่อสลับระหว่างพิมพ์คีย์บอร์ดกับกระดาษเส้นบรรทัดสำหรับเขียนด้วย Apple Pencil (หรือแค่เอาหัวปากกาแตะในช่อง ระบบจะสลับเป็นโหมด Pencil ให้อัตโนมัติ!)
ภาพที่ 4: แถบสลับ [ Type | Pencil ] (หมายเลข ①) ข้างช่องข้อความ Note / Comment และช่อง Replies
ตั้งค่าบน iPad เพื่อให้เขียนไทย-อังกฤษแปลงเป็นตัวอักษรได้ทันที (ทำครั้งเดียว):
  1. ไปที่ iPad Settings → Apple Pencil → เปิด Scribble (ขีดเขียน)
  2. ไปที่ Settings → General → Keyboard → Keyboards → ตรวจว่ามีแป้นพิมพ์ Thai (ไทย) และ English เพิ่มไว้แล้ว
  3. เวลาเขียนใน NEXAR แค่เขียนทับบนเส้นบรรทัดได้เลย และสลับภาษาไทย/อังกฤษจากแถบลอยของ Apple Pencil ที่มุมล่างจอ iPad ได้ทันที (ทำงานออฟไลน์ 100%)

7 ซ้อนโมเดลในกล้องสด (CAM) & ล็อกด้วย QR

  1. กดปุ่ม CAM บน Bottom Dock (ระบบจะสลับเข้าโหมด Walk และเปิดกล้องหลังอัตโนมัติ)
  2. เปิด GYRO แล้วกด PLACE → แตะลงบนพื้นจริงในภาพกล้องเพื่อวางโมเดลที่สเกลจริง (หรือกด QR LOCK แล้วส่องแผ่น QR ที่พิมพ์จากเมนู ••• → Create Site QR เพื่อล็อกพิกัดแม่นยำ)
  3. ปรับสไลเดอร์ MODEL % (ความโปร่งแสง), FOV (มุมเลนส์กล้อง) และ HEIGHT (ความสูงกล้อง) ให้ตรงกับของจริง แล้วกด Capture (C) เพื่อบันทึกทั้งภาพซ้อนโมเดลและภาพถ่ายจริงเก็บเข้า Group
ข้อจำกัดบนเว็บแอป iPad: ต้องเปิดผ่าน HTTPS (เช่น GitHub Pages) เพื่อใช้กล้อง และหากเดินย้ายจุดไกลๆ โมเดลจะไม่ตามอัตโนมัติ ให้กด PLACE หรือส่อง QR LOCK ใหม่ที่จุดยืนถัดไปครับ

8 คู่มือการส่งออก (Export ▾ มุมขวาบน)

9 การใช้งานร่วมกับ Revit & BIM Software

ขาไป: Revit → NEXAR

  1. ใน Revit: File → Export → IFC (แนะนำ IFC4 Reference View)
  2. กด Modify Setup → Property Sets ติ๊ก Store the IFC GUID in an element parameter after export (เพื่อให้ปลั๊กอินขากลับจับตัว Object จริงได้แม่น 100%)
  3. ตรวจ Coordinate Base ให้ตรงกันทุกครั้ง (เช่น Project Base Point หรือ Shared Coordinates)
  4. นำไฟล์ .ifc เปิดใน NEXAR ด้วยปุ่ม Open

ขากลับ: NEXAR → Revit / Navisworks

  1. กด Export ▾ → IFC Export Spot (.ifc)
  2. ใน Revit: Insert → Link IFC เลือกวางแบบ Origin to Origin — จะเห็นหมุด 3 รูปทรง 3 สีลอยตรงพิกัดจริงทันที
  3. คลิกที่หมุดจะเห็นพารามิเตอร์ทั้งหมดใน NEXAR_Markup (Tag, RecordKind, Status, CheckedAt, X/Y/Z, UniFormat, HostRevitId, CamEye)
  4. หากมีการอัปเดตหน้างานรอบใหม่ แค่ Export ทับชื่อเดิมแล้วกด Manage Links → IFC → Reload ใน Revit ได้ทันที!

10 ติดตั้งบน iPad / มือถือ และวิธีอัปเดตเวอร์ชัน

ติดตั้งเป็นแอปหน้าจอโฮม (PWA)

  1. เปิดลิงก์ GitHub Pages ของ NEXAR ใน Safari (iPad/iPhone) หรือ Chrome (Android)
  2. Safari: กดปุ่ม Share → Add to Home Screen · Chrome: เมนู ⋮ → Install app
  3. เปิดใช้งานจากไอคอนบนหน้าจอ ใช้งานออฟไลน์หน้างานได้ทันที

อัปเดตเวอร์ชันใหม่

  1. อัปโหลด ทั้งโฟลเดอร์ Nexar ขึ้น GitHub (แทนที่ไฟล์เดิมทั้งหมด)
  2. รอ 1–2 นาที แล้วเปิดแอป ดูมุมล่างว่าเลขเวอร์ชันตรงกับคู่มือนี้ (ตอนนี้ v2.7.0)
  3. บนคอมทดสอบได้ทันทีโดยดับเบิลคลิก Start NEXAR.bat แล้วเปิด http://localhost:5173
