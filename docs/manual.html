คู่มือ NEXAR

ดูโมเดล BIM (IFC / DXF / GLB) บน iPad มือถือ หรือคอม แล้วมาร์คปัญหา ถ่ายภาพ และซ้อนโมเดลในภาพกล้องที่หน้างาน จากนั้นส่งผลกลับไปที่ Revit หรือส่งให้คนอื่นดู

เริ่มใช้งานใน 5 ขั้น

  1. เปิดโมเดล แท็บ Home → Open Model → เลือกไฟล์ .ifc (จาก Revit: File → Export → IFC) ไฟล์จะถูกเก็บในเครื่อง ครั้งต่อไปไม่ต้องเปิดใหม่
  2. ดูโมเดล ใช้ 3D หมุนดูรอบๆ, Plan ดูแบบแปลน, Walk เดินข้างใน (มีจอยซ้าย-ขวาให้)
  3. มาร์คจุด แท็บ Markup → Comment / Note / Issue แล้วแตะบนโมเดล → พิมพ์ข้อความ (แนบรูปได้)
  4. ที่หน้างาน เข้า Walk → กด CAM → PLACE หรือ QR LOCK ให้โมเดลซ้อนตรงกับของจริง → Capture
  5. ส่งออก แท็บ Export → Interactive HTML (ส่งให้ใครดูก็ได้) หรือ IFC + Marks (เอาเข้า Revit เป็นวัตถุจริง)
จำไว้: ข้อมูลทั้งหมดอยู่ในเครื่องนั้น (ไม่มี cloud) ถ้าจะย้ายเครื่องให้ Export → Project JSON แล้ว Import JSON ที่อีกเครื่อง ไฟล์โมเดลต้องเปิดใหม่อีกครั้ง

มาร์ค คอมเมนต์ ถ่ายภาพ

ปุ่มใช้เมื่อวางตรงไหน
Comment Note Issueมาร์คปัญหาพร้อมข้อความ / รูปแตะบนโมเดลจุดที่ต้องการ
Markมาร์คเร็วๆ ตอนเดินตรง กากบาทกลางจอ
Captureถ่ายภาพหน้าจอเก็บ (เข้า Group ที่เลือกอยู่)ตรงกากบาทกลางจอ · ถ้าเปิด CAM จะได้ภาพโมเดลซ้อนภาพจริง + ภาพจริงอีก 1 รูป
  • ถ้าแตะโดนชิ้นส่วน (ผนัง เสา ท่อ) มาร์คจะ ผูกกับ element นั้น (เก็บ IFC GUID) Revit / BCF จะชี้ไปที่ชิ้นนั้นได้
  • เลือกมาร์ค: แตะหมุด หรือเลือกใน Panel → Markups แล้วใช้ Edit Lock Resolve Delete
  • Lock = ห้ามแก้/ลบ (กันมือพลาด) · Resolve = แก้แล้ว (หมุดเปลี่ยนสี)
  • มาร์คถูกบันทึกเป็น พิกัดโมเดล (เมตร, แกน Z ขึ้น) ไม่ใช่พิกัดหน้าจอ ส่งออกไปที่ไหนก็อยู่ตำแหน่งเดิม

Group (ชุดภาพต่อกัน)

Group ใช้รวมภาพ/มาร์คเป็นชุด เช่น "ตรวจชั้น 2 วันที่ 21" ภาพใน Group จะเรียงต่อกันตามลำดับที่ถ่าย

  1. กดชิป Group ด้านล่าง (หรือ Home → Group) → สร้าง/เลือก Group
  2. กด Capture หรือ Mark ทุกอันจะเข้า Group นั้นจนกว่าจะเปลี่ยน
  3. ตอนส่งออก Group จะติดไปด้วย: BCF = Label, IFC = IfcGroup "NEXAR: ชื่อกลุ่ม", HTML = แสดงในรายการ

ซ้อนโมเดลในกล้อง (CAM)

ใช้ดู "แบบ vs ของจริง" ที่หน้างาน: ภาพกล้องอยู่ด้านหลัง โมเดลซ้อนอยู่ด้านบนในสเกลจริง

  1. เข้า Walk → กด CAM (ครั้งแรกเครื่องจะถามสิทธิ์กล้อง กด Allow) · เปิด GYRO ด้วย
  2. ยืนที่จุดอ้างอิง (เช่น มุมเสา) ตั้ง HEIGHT = ความสูงที่ถือเครื่อง (ปกติ 1.5–1.6 m)
  3. กด PLACE แล้วแตะพื้นในภาพกล้องตรงจุดที่ควรเป็นกลางฐานโมเดล หรือใช้ QR LOCK ถ้ามีป้าย QR (แม่นกว่า)
  4. หมุนให้ตรงด้วย ⟲ 5° ⟳ (แตะ = 5°, กดค้าง = หมุนต่อเนื่อง)
  5. ปรับ FOV จนขนาดโมเดลเท่าของจริง และ MODEL 0–100% (ความทึบของโมเดล)
  6. กด Capture ได้ภาพโมเดลซ้อนภาพไซต์ + ภาพไซต์จริง เก็บเข้า Group
ตัวปรับความหมาย
OVERLAY / SPLITOVERLAY = โมเดลซ้อนเต็มจอ · SPLIT = กล้องเล็กมุมขวาบน
MODEL0% = เห็นแต่ของจริง · 100% = เห็นแต่โมเดล
FOVมุมกว้างของเลนส์ ค่าเริ่ม 45° ถ้าโมเดลดูใหญ่/เล็กกว่าของจริงให้ปรับตัวนี้ (ตั้งครั้งเดียวต่อเครื่อง)
HEIGHTความสูงกล้องจากพื้น ผิด 10 cm ก็ทำให้ระยะไกลเพี้ยนได้
สำคัญ: แอปบนเว็บรู้แค่ว่าเครื่อง หมุน ไปทางไหน แต่ไม่รู้ว่าคุณ เดิน ไปเท่าไร ยืนที่เดิมแล้วหันดูได้ตรงตลอด แต่ถ้าเดินไปจุดอื่นต้อง PLACE / QR LOCK ใหม่ หรือดันจอย MOVE ตามระยะที่เดิน (ดู ข้อจำกัด)

QR ที่หน้างาน

  1. View → Create QR → แตะจุดบนโมเดลที่จะติดป้าย (เช่น หน้าเสา C3) → ทำตามขั้นตอนบนจอ (แนวติดพื้นหรือติดผนัง)
  2. พิมพ์แผ่น A4 แบบ ขนาดจริง (100%, ห้าม fit to page) ขนาดสี่เหลี่ยม QR ต้องเท่าที่ระบุบนแผ่น
  3. ติดแผ่นตรงจุดนั้นที่หน้างาน (ให้ช่างสำรวจวางตำแหน่งได้ยิ่งดี)
  4. ที่หน้างาน: Walk → CAM → QR LOCK → ส่องป้ายให้เห็นทั้งแผ่น ห่าง 1–2 m จนขึ้น ✓ โมเดลจะล็อกตำแหน่งและทิศให้เอง
เคล็ดลับ: ติด QR หลายแผ่น (ทุกโซน/ทุกชั้น) เดินถึงโซนไหนก็ QR LOCK ใหม่ จะได้ตรงเสมอ ทดสอบแล้วคลาดประมาณ 6 cm และ 2°

Interactive HTML ทำอะไรได้

  • หมุน/ซูมโมเดล แตะหมุดหมายเลขแล้วกล้องจะบินไปที่จุด พร้อมการ์ดรายละเอียด (ข้อความ สถานะ ผู้มาร์ค พิกัด รูป)
  • ค้นหา และกรองตามประเภท ปุ่ม Marks (ซ่อน/แสดงหมุด) X-Ray Model Fit
  • ไฟล์ใหญ่ตามขนาดโมเดลและจำนวนรูป ถ้าเกิน ~25 MB อาจส่งทางแชทไม่ได้ ให้ใช้ Google Drive / OneDrive

IFC + Marks ทำอะไร

ทุกมาร์คกลายเป็นวัตถุเล็กๆ (ทรงกระบอก Ø150 mm) ใน IFC ตรงตำแหน่งที่มาร์ค ไม่ต้องใช้ point cloud เพราะตำแหน่งมาจากพิกัดโมเดลโดยตรง

  • ถ้าเปิดโมเดล IFC ไว้ จะ ต่อท้ายไฟล์ IFC เดิม (หน่วย ชั้น และจุดอ้างอิงเดิม ข้อมูลเดิมไม่ถูกแก้) ใช้ได้ทั้ง IFC2X3 และ IFC4 ทั้งหน่วยเมตรและมิลลิเมตร
  • ถ้าเปิดแค่ DXF/GLB จะได้ IFC4 ที่มีแต่มาร์ค ในพิกัดเดียวกับโมเดล
  • ประเภท: IfcBuildingElementProxy (ใน Revit = Generic Model) อยู่ในชั้น (Storey) ที่ใกล้ที่สุดด้านล่างของจุด
ข้อมูลในวัตถุค่า

Descriptionข้อความคอมเมนต์เต็ม

สีComment / Note / Issue / Capture คนละเฉดน้ำเงิน

เปิดใน Revit

แบบ IFC + Marks (แนะนำ)

  1. Revit → Insert → Link IFC → เลือกไฟล์ _NEXAR-marks.ifc (หรือ File → Open → IFC)
  2. ถ้าโมเดลหลักใน Revit ใช้จุดอ้างอิงเดียวกับตอน export IFC ให้วางแบบ Origin to Origin / Shared Coordinates ตามที่ export มา
  3. คลิกหมุด (Generic Model) → Properties จะเห็น Name / Description และพารามิเตอร์จาก NEXAR_Markup (Title, Status, Author …)
  4. ทำ schedule หรือ filter ตาม Status / Type ได้ เพื่อติดตามงาน
ถ้าไม่อยากได้ทั้งโมเดลซ้ำ: ยังไม่มีปุ่ม export เฉพาะมาร์ค เมื่อมีโมเดล IFC เปิดอยู่ ให้ปิด (ซ่อน) โมเดล IFC ใน View → Models ก่อน export จะได้ไฟล์ที่มีแต่มาร์คแทน (ฟีเจอร์นี้อยู่ใน TODO)

แบบ BCF

ติดตั้ง add-in BCF (เช่น BIMcollab Zoom / BCF Manager) → Import .bcfzip → คลิก topic แล้ว Revit จะซูมไปที่ชิ้นส่วนนั้น

ติดตั้ง / อัปเดตแอป

ติดตั้งบน iPad / มือถือ

  1. เปิดลิงก์ GitHub Pages ของ NEXAR ใน Safari (iPad/iPhone) หรือ Chrome (Android)
  2. Safari: ปุ่ม Share → Add to Home Screen · Chrome: เมนู ⋮ → Install app
  3. เปิดจากไอคอนบนหน้าจอ ใช้ออฟไลน์ได้หลังเปิดครั้งแรก

อัปเดตเวอร์ชัน

  1. อัปโหลด ทั้งโฟลเดอร์ Nexar ขึ้น GitHub (แทนที่ไฟล์เดิมทั้งหมด)
  2. รอ 1–2 นาที แล้วเปิดแอป ดูมุมล่างว่าเลขเวอร์ชันตรงกับคู่มือนี้ (ตอนนี้ v2.6.0)
  3. ถ้ายังเป็นเลขเก่า: ปิดแอปให้หมดแล้วเปิดใหม่ หรือดึงหน้าจอลงเพื่อรีเฟรช
บนคอม (ทดสอบ): ดับเบิลคลิก Start NEXAR.bat ในโฟลเดอร์ Nexar แล้วเปิด http://localhost:5173

เดินแล้วโมเดลเลื่อนไม่ตรงปกติของเว็บแอป ให้ PLACE / QR LOCK ใหม่ที่จุดใหม่
QR LOCK ไม่ติดส่องให้เห็นทั้งแผ่น ห่าง 1–2 m แสงพอ ไม่สะท้อน · พิมพ์ขนาดจริง 100%
Revit ไม่เห็นหมุดตรวจว่า Link แบบ Origin to Origin / Shared · หมุดเล็ก (15 cm) ให้ซูมเข้าหรือใช้ schedule หา "NAR-"
Export แล้วหาไฟล์ไม่เจอดู ไฟล์ที่ export ไปอยู่ไหน · iPad ต้องกด Save to Files ในกล่อง File ready
LINE ขึ้น "file types that can't be shared"ใช้ปุ่ม Send as ZIP แทน LINE รับไฟล์ .zip
ไฟล์ HTML ใหญ่เกินส่งลดรูปในมาร์ค หรืออัปโหลดขึ้น Drive แล้วส่งลิงก์

ข้อจำกัดที่ต้องรู้

  • เดินแล้วโมเดลไม่ตามเอง เพราะเว็บแอปบน iPad ไม่มีระบบติดตามตำแหน่ง (ARKit) ใช้หลัก "ยืนจุด → ล็อก → หันดู → ถ่าย → ย้ายจุดแล้วล็อกใหม่" ถ้าต้องการเดินแล้วตามเองต้องเป็นแอป Unity / native (แผนในอนาคต)
  • ความแม่นของ CAM ขึ้นกับ HEIGHT, FOV และจุดอ้างอิง QR แม่นที่สุด
  • ข้อมูลอยู่ในเครื่องเดียว ไม่มีการซิงก์ ต้อง export/import เอง
  • เปิด DWG / RVT ตรงๆ ไม่ได้ ให้ export เป็น IFC หรือ DXF
  • ระบบ GPS / นับก้าว / Site / AR เก่า ถูกพักไว้ (ปิดซ่อน ยังไม่ลบโค้ด)
